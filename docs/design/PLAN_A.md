# План A — Claude Design (визуальное направление)

> Цель: до правки кодовой базы зафиксировать дизайн-систему и утвердить визуал
> на статичных макетах-вариациях. Артефакт передаётся в План B.
>
> Решения заказчика: шрифты оставляем (Playfair Display + IBM Plex);
> dark mode — делаем с переключателем.
>
> Метки: 🆕 — добавлено по итогам живого визуального аудита; ✏️ — изменён приоритет.

## D1. Токены и палитра
- Light + dark наборы семантических токенов.
- ✏️ **Первой задачей — заменить серый `#3F4C50`.** Это якорь редизайна: hero/шапка/футер
  уходят на светлую схему (или красный блок-логотип). Без этого остальное косметика.
- 🆕 **Курируемая палитра серий — 6 цветов**, спроектированная и проверенная (контраст +
  дальтонизм). Сейчас в `subsidy-count` фиолетовый off-brand, бирюза и голубой сливаются —
  палитру пересобрать с нуля, голубой бренда `#C3D7E0` сделать осмысленным членом ряда,
  фиолетовый убрать.

## D2. Чарт-стайлгайд
- 6 типов графиков с правилами (линия, area, бары, combo bar+line, stacked/доли, спарклайн).
- 🆕 **Direct-label последней точки + аннотации пиков** (всплески 2020/2023 на ипотеке
  просятся быть подписанными) — заложить в эталон.
- 🆕 **Решить судьбу area-градиента**: сейчас `.18→.02` практически невидим. В макете
  показать рабочую плотность заливки (либо заметная, либо линия без area).
- 🆕 **Перерисовать ручки dataZoom** — сейчас грубые красные «таблетки». Тонкий минималистичный скруббер.
- Стиль тултипа, ось, единицы в подписи оси Y, формат чисел RU, состояние «нет данных».

## D3. Макеты экранов (light + dark, desktop + mobile)
- `index`, `category`, `chart`, 1 комбо-страница.
- 🆕 **Карточка раздела с контентом** — не пустая плашка: спарклайн ключевого показателя
  или главная цифра + дельта. Отдельный важный макет.
- 🆕 **Адаптив `category` <900px** — спроектировать поведение навигации (сейчас сайдбар
  уезжает простынёй из 14 ссылок наверх). Варианты: горизонтальные табы / выпадающий select / off-canvas.
- ✏️ **KPI-плашка `chart`** — сейчас широкая и полупустая. Уплотнить либо добавить третий
  смысловой блок (мин/макс, тренд-спарклайн).

## D4. Компоненты и фирменные элементы
- 🆕 **Набор SVG-иконок разделов** (18 категорий, единый line-стиль) — заменить эмодзи.
  Отдельный обязательный артефакт.
- 🆕 **Спарклайн-компонент — один канон** (сейчас у части строк area-fill, у части нет —
  выглядит багом). Зафиксировать единый вид.
- 🆕 **Видимый индикатор кликабельности тоггл-серий** (сейчас точки «Первичный ●» не
  читаются как кнопка).
- Дельта-бейдж, тултип, состояния loading/**empty/error** (сейчас error-состояния нет вообще),
  переключатель темы, стрелка/зигзаг бренда.

## D5. Выбор направления hero
- 2–3 варианта → выбрать. Дефолт: светлый + красный акцент + лёгкий зигзаг.

**Артефакт:** `design-mockups.html` (тумблер вариантов + dark/light) + `DESIGN_SPEC.md`.

## Контекст бренда (из гайдлайна MACON / Artsdelka)
- Цвета: red `#C8181A`, light-blue `#C3D7E0` (CMYK 30·6·10·0), black, white.
- Фирменные шрифты гайдлайна: Bebas Neue (акцент), Akrobat (доп.) — но для веба **оставляем
  текущие** Playfair + IBM Plex по решению заказчика.
- Фирменные элементы: стрелка «`>`», зигзаг-паттерн (W/M, светло-голубой), красная «осциллограмма».
- Серый `#3F4C50` — артефакт текущего сайта, НЕ из бренда, подлежит замене.
